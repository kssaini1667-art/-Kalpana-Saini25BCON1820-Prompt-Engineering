# Session 5 — Python Programming

## About
This folder contains basic Python programs created for practice. These programs cover loops, conditional statements, dictionaries, and basic mathematical operations.

## Programs Included

| File Name | Description |
|---|---|
| `Factorial.py` | Calculates the factorial of 5 using a for loop. |
| `Febonacci.py` | Prints the first 10 Fibonacci numbers. |
| `Dictionary.py` | Creates a student dictionary and displays its key-value pairs. |
| `EvenOdd.py` | Takes a number from the user and checks whether it is even or odd. |
| `PrimeNumber.py` | Takes a number from the user and checks whether it is prime. |
| `SumNaturalNumbers.py` | Calculates the sum of natural numbers up to the number entered by the user. |

## Requirements
- Python 3
- No external libraries are required.

## How to Run
1. Install Python 3.
2. Open a terminal in this folder.
3. Run any program using:

```bash
python Factorial.py
```

Replace `Factorial.py` with the name of the program you want to run.

## Learning Outcomes
- Using `for` loops
- Using `if-else` statements
- Taking input from the user
- Working with Python dictionaries
- Performing basic mathematical calculations
