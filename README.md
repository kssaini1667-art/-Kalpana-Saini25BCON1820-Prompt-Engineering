## Session 3 - Testing AI & Reverse Prompting

Session 3 focused on testing AI responses, understanding how prompt framing influences AI output, and verifying AI-generated answers before trusting them.

The session included:

- Testing AI responses using confident and neutral prompts
- Compiling and running the palindrome program before asking AI
- Identifying the bug in the palindrome checker
- Using reverse prompting for self-critique
- Checking AI confidence and comparing responses
- Understanding the risks of unverified AI output

The main principle of the session was:

> Ask. Verify. Then trust.
