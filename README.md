## Session 3 — Testing AI & Reverse Prompting

Session 3 focused on testing AI responses, comparing different prompts, and verifying AI-generated answers instead of trusting them automatically.

The session included:

- Testing AI responses with different prompt styles
- Comparing AI responses and confidence scores
- Practicing reverse prompting and self-critique
- Writing and testing C programs
- Compiling and running code to verify its output
- Understanding why AI confidence does not guarantee correctness

Programs included `average.c` and `palindrome.c`.

The main principle of this session was:

> Ask. Verify. Then Trust.

## Session 4 — From C to Python with AI

Session 4 focused on translating basic C programs into Python and understanding the differences between the two programming languages.

The session included:

- Working with Google Colab notebooks
- Practicing factorial and Fibonacci programs
- Understanding Python dictionaries
- Converting C structure-based data into Python dictionaries
- Comparing C and Python syntax
- Running programs and checking their outputs
- Using AI to review and assist with code translation
- Documenting differences between C and Python

The homework included translating programs, comparing outputs, identifying mismatches, preparing a cheat sheet, and writing a reflection.

The main principle of this session was:

> Translate. Run. Compare. Verify.

## Session 5 — Python Basics & GitHub Workflow

## Session 6 — Cursor: AI Inside the Editor

Session 6 focused on using Cursor as an AI-assisted code editor and understanding how AI can help improve existing Python code.

The session included:

- Exploring Cursor editor features and modes
- Creating project-specific rules using `.cursor/rules/python-standards.mdc`
- Working with the `messy_report.py` program
- Refactoring code into an improved version
- Comparing the original and refactored programs
- Recording program outputs in text files
- Understanding how coding rules guide AI-assisted development

Files included `messy_report.py`, `messy_report_rf.py`, `original_output.txt`, and `rf_output.txt`.

The main goal was to learn how to use AI tools inside a code editor while checking the results of code changes.
